## 🔄 데이터 흐름

### 1. 사용자 요청 처리 플로우

```
사용자 요청
    │
    ▼
[Nginx 리버스 프록시]
    │
    ├─→ 정적 파일 요청 ──→ /static, /uploads 직접 서빙
    │
    └─→ 동적 요청
        │
        ▼
    [Flask 애플리케이션]
        │
        ├─→ 캐시 확인 ──→ [Redis] ──→ 캐시 히트 시 즉시 응답
        │                      │
        │                      └─→ 캐시 미스 시 계속
        │
        ├─→ 데이터베이스 조회 ──→ [PostgreSQL]
        │
        ├─→ 비즈니스 로직 처리
        │
        ├─→ 결과 캐싱 ──→ [Redis]
        │
        └─→ 응답 생성
            │
            ▼
        [Nginx] ──→ 사용자에게 응답
```

## 🔄 환경별 차이

### 개발 vs 프로덕션

```
┌─────────────────┬──────────────────┬──────────────────┐
│     항목        │    개발 환경      │   프로덕션 환경   │
├─────────────────┼──────────────────┼──────────────────┤
│ Flask 모드      │ DEBUG = True     │ DEBUG = False    │
│ 워커 수         │ 1                │ 4+               │
│ 핫 리로드       │ ✓ 활성화         │ ✗ 비활성화       │
│ 볼륨 마운트     │ ✓ 코드 마운트    │ ✗ 이미지 빌드    │
│ GUI 도구        │ ✓ Adminer, etc   │ ✗ 없음           │
│ SSL/TLS         │ ✗ HTTP만         │ ✓ HTTPS          │
│ 리소스 제한     │ ✗ 없음           │ ✓ 제한 설정      │
│ 로깅 레벨       │ DEBUG            │ INFO/WARNING     │
│ 데이터베이스    │ 작은 데이터      │ 프로덕션 데이터  │
└─────────────────┴──────────────────┴──────────────────┘
```
